# 🎵 DXAudio

**DXAudio** — это продвинутый аудиоплеер для Android, написанный на Kotlin с использованием Jetpack Compose и Media3 (ExoPlayer). 

> ⚠️ **Важное примечание:** Этот проект создан с помощью **вайбкодинга** (Vibe-coding). Код писался в тандеме с нейросетями (AI), а сборка происходила полностью на GitHub Actions, без использования Android Studio. Это эксперимент, который доказывает, что даже без глубоких знаний Java/Kotlin можно собрать функциональное приложение.

## ✨ Основные фишки

- **Множество кодеков:** Благодаря `NextLib` плеер понимает не только стандартные MP3/AAC/FLAC, но и редкие форматы вроде ALAC, AC3, DTS и TrueHD.
- **Визуализатор:** Встроенный анализатор аудио на базе `android.media.audiofx.Visualizer` (как в *Cava* или *AIMP*). Поддерживает два режима: «Волна» и «Спектр».
- **Кастомные темы (.dxth):** Встроенный движок тем. Темы — это ZIP-архивы с JSON-файлом внутри. Вы можете менять цвета интерфейса на лету. В комплекте идут темы «Golden Luxury», «Neon Lime» и «Dark Amethyst».
- **Текст песен (LRC):** Поддержка синхронизированных текстов песен (формат `.lrc`). Если текст найден, он будет плавно прокручиваться в такт музыке.
- **Файловый менеджер и плейлисты:** Встроенный проводник показывает только папки и аудиофайлы. Поддерживается создание и воспроизведение плейлистов `.m3u`.
- **Режим «Картинка в картинке» (PiP):** Готов к работе в фоновом режиме.
- **Поддержка «Открыть с помощью»:** Приложение перехватывает открытие аудиофайлов, плейлистов и файлов тем (.dxth) из проводника.

## 🛠 Технологии

- **Язык:** Kotlin
- **UI:** Jetpack Compose (Material 3)
- **Аудио-движок:** AndroidX Media3 (ExoPlayer)
- **Расширенные кодеки:** [NextLib](https://github.com/anilbeesetti/nextlib)
- **Сборка:** GitHub Actions (Workflow: `Build DXAudio APK`)

## 🚀 Как собрать

Поскольку проект не требует установки Android Studio, сборка происходит автоматически в облаке GitHub:
1. Внесите изменения в код.
2. Перейдите во вкладку **Actions** в вашем репозитории.
3. Выберите workflow **Build DXAudio APK** и нажмите **Run workflow**.
4. Через пару минут скачайте готовый `app-debug.apk` из раздела **Artifacts**.
